# Windows Server 2019 System Administration Lab

## Overview
Configured and managed a Windows Server 2019 virtual machine to perform enterprise-style system administration, Active Directory management, security configuration, and IT support tasks in a lab environment.

## Environment
- Windows Server 2019 Datacenter
- Hyper-V Virtual Machine
- Active Directory Domain Services (AD DS)
- PowerShell
- Print Management
- Security Configuration Tools

## Tasks Performed

### Active Directory Administration
- Created and managed organizational units (OUs)
- Configured user accounts and security groups
- Managed passwords, profiles, and permissions
- Performed domain-based administration using Active Directory Users and Computers

### PowerShell Administration
Used PowerShell commands to:
- Enumerate local users
- Review running services
- Retrieve system configuration information

### Printer Management
- Installed and configured printers
- Managed printer drivers
- Verified printer availability and connectivity

### VPN & Remote Access
- Configured VPN connection settings
- Tested remote access configuration

### Security Configuration
- Configured Security Templates
- Used Security Configuration and Analysis tools
- Reviewed Windows security settings and policies

### Troubleshooting & System Management
Performed troubleshooting for:
- Network connectivity
- User account access
- Shared resource availability
- Printer connectivity
- Service management

## Skills Demonstrated
- Windows Server administration
- Active Directory management
- PowerShell administration
- IT infrastructure troubleshooting
- Enterprise system configuration
- Security policy configuration

Successfully configured and administered a Windows Server 2019 environment while practicing real-world enterprise IT support and system administration tasks.
